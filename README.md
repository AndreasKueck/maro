# Ret-apo "Prognozo de akvoniveloj per TICON-4-datumoj" kaj Android-apo "Maro"
Tio chi estas la Guglo-Apoj-Skripto-pakajho por la supre menciitaj apoj. La apoj eligas akvonivelojn prognozitajn por loko kaj dato specifeblaj fare de la uzanto. Temas pri privata neoficiala prognozo ne tauga por navigaciaj celoj.
